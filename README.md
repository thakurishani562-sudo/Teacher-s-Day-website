## 🌸 Teacher's Day Contribution Tracker

A little contribution, a lot of gratitude. ♡

A simple and elegant Teacher's Day contribution website created for the 1st Year Information Technology students to collectively contribute towards making Teacher's Day special.

---

## ✨ About the Project

This website provides a transparent and visually appealing way to manage our class's Teacher's Day contributions.

It allows students to:

- 💰 View the total collection
- 📅 Track today's collection
- 👥 See the number of contributors
- 📊 Track our contribution progress
- 🧾 View recent contributions
- 💌 Share messages for our teachers
- ➕ Add their contribution

The design combines a warm Teacher's Day aesthetic with a clean, modern dashboard interface.

---

The website follows a soft floral Teacher's Day theme inspired by:

🌸 Hand-painted floral illustrations

📖 Elegant typography
✨ Minimal and subtle UI elements

## 📱 Features

📊 Contribution Dashboard

A quick overview of the total and today's collection.

📈 Progress Tracking

Shows how close the class is to reaching the contribution goal.

🧾 Recent Contributions

Displays recent contributions to maintain transparency within the class.

💌 Student Messages

A small space for students to leave meaningful messages for their teachers.

📱 Responsive Design

Designed to work across desktop, tablet and mobile screens.

## 🚀 Getting Started

Clone the repository:

git clone https://github.com/thakurishani562-sudo/Teacher-s-Day-website.git

Navigate to the project:

cd Teacher-s-Day-website

Install dependencies:

npm install

Start the development server:

npm run dev
